QuantizableMobileNetV3 torchvision_down.models.quantization.mobilenetv3.mobilenet_v3_large ( bool pretrained = False,
bool progress = True,
bool quantize = False,
**Any kwargs ) 
Constructs a MobileNetV3 Large architecture from
`"Searching for MobileNetV3" <https://arxiv.org/abs/1905.02244>`_.

Note that quantize = True returns a quantized model with 8 bit
weights. Quantized models only support inference and run on CPUs.
GPU inference is not yet supported

Args:
 pretrained (bool): If True, returns a model pre-trained on ImageNet.
 progress (bool): If True, displays a progress bar of the download to stderr
 quantize (bool): If True, returns a quantized model, else returns a float model
