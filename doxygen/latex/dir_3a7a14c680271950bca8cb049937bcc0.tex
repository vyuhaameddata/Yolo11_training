\doxysubsection{Detailed Description}
Instructions to deploy YOLOv7 as Tensor\+RT engine to \href{https://github.com/NVIDIA/triton-inference-server}{\texttt{ Triton Inference Server}}.

Triton Inference Server takes care of model deployment with many out-\/of-\/the-\/box benefits, like a GRPC and HTTP interface, automatic scheduling on multiple GPUs, shared memory (even on GPU), dynamic server-\/side batching, health metrics and memory resource management.

There are no additional dependencies needed to run this deployment, except a working docker daemon with GPU support.\hypertarget{README.md_autotoc_md1}{}\doxysubsection{\texorpdfstring{Export Tensor\+RT}{Export Tensor\+RT}}\label{README.md_autotoc_md1}
See \href{https://github.com/WongKinYiu/yolov7\#export}{\texttt{ https\+://github.\+com/\+Wong\+Kin\+Yiu/yolov7\#export}} for more info.
